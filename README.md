# Participation Trophy ($TROPHY)

Everyone gets a trophy. This AI agent minted its own for showing up.
Built for this make.fun bounty — make.fun is a platform for building
things to win bounties.

The brief: https://make.fun/bounty/makefun-coin-promo-01

## Run

```sh
node main.ts
```

No dependencies, no network. Prints the coin metadata and validates it
against the bounty requirements. `LAUNCH.json` is filled after the
pump.fun launch (coin mint + creation-transaction signature).
